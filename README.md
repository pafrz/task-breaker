# Task Breaker ⚡

AIが課題をタスクに分解し、時間管理をサポートするWebアプリ

**🔗 Live Demo:** https://task-breaker-one.vercel.app

---

## 📌 概要

| 項目 | 内容 |
|------|------|
| **アプリ名** | Task Breaker |
| **種別** | Webアプリ（シングルページ） |
| **目的** | 課題・作業のタスク分解と時間管理の両立 |
| **対象** | 課題の終わりが見えずに長時間作業してしまう人 |

---

## 🎯 課題の背景

> 「作業に集中しすぎて、気づいたら深夜になっていた」

作業に没頭すると **時間の感覚がなくなり**、終わりが見えないまま徹夜してしまうことがある。結果として睡眠不足や生活習慣の乱れにつながる。

このアプリはその問題を2つのアプローチで解決する：

1. **事前に終わりを見える化する** — AIが課題をタスクに分解し、合計・残り時間を表示
2. **超過したら即通知する** — タイマーが0になっても継続でき、超過時間を赤字で見せることで「やりすぎ」を自覚させる

---

## ✨ 機能一覧

| 機能 | 詳細 |
|------|------|
| 🤖 **AI タスク生成** | OpenAI GPT-4o-mini が課題を自動でタスクに分解・時間見積もり |
| ⏱ **カウントダウンタイマー** | タスクごとに作業タイマーを起動。円グラフで残り時間を可視化 |
| 🔴 **超過タイマー** | 0になっても継続カウントアップ（赤表示）。+5/+10/+15分の延長ボタン付き |
| 📅 **締め切り設定** | 課題全体に締め切り日を設定。「あと○日」バッジで残り日数を確認 |
| ⭐ **優先度設定** | タスクに高/中/低の優先度をつけて自動ソート |
| 📝 **タスクメモ** | 各タスクに補足メモを追加 |
| ✏️ **タスク編集** | タスク名・時間をインライン編集 |
| ➕ **タスク追加/削除** | 手動でタスクの追加・削除 |
| 💾 **進捗の自動保存** | localStorage で進捗・履歴を永続化（ページを閉じても保持） |
| 📚 **履歴管理** | 最大20件の課題履歴を保存・切り替え |
| 📱 **スマホ対応** | レスポンシブデザイン |

## 🎯 使い方

1. **API キーを入力** — OpenAI Platform で発行したキーを入力（ブラウザ内のみ保存）
2. **課題を入力** — 「期末レポート」「プレゼン準備」など、取り組む課題を入力
3. **「分解する」をクリック** — AIが自動でタスクに分解・作業時間を見積もり
4. **締め切りと優先度を設定** — 各タスクに優先度をつけて自動ソート
5. **タイマーで作業** — タスクのタイマーを起動して時間内に完了を目指す
6. **超過したら延長** — 時間を超えたら+5/+10/+15分で延長して継続
