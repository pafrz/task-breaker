# Task Breaker ⚡

AIが課題をタスクに分解し、「終わりが見えない作業による徹夜」を仕組みで防ぐタブ式Webアプリ

**🔗 Live Demo:** https://task-breaker-one.vercel.app  
（APIキーが無くても「🎁 サンプルで試す」からすぐ触れます）

## 🎯 課題の背景

> 「作業に集中しすぎて、気づいたら深夜になっていた」

作業に没頭すると **時間の感覚がなくなり**、終わりが見えないまま徹夜してしまう。結果として睡眠不足や生活習慣の乱れにつながる。

このアプリは4つのアプローチで解決する：

1. **事前に終わりを見える化する** — AIが課題をタスクに分解し、合計・残り時間を表示
2. **画面を見ていなくても割り込む** — 予定時間を超えたら音とブラウザ通知で知らせる
3. **開始前に合格ラインを宣言する** — 「今日これができたら合格」を作業前に決めて、終了後に照合する。完成後に基準を吊り上げる癖を仕組みで殴る
4. **見守るキャラが心配してくれる** — マスコット「ネム」が状況に応じて表情とセリフを変え、超過時は真剣に「寝よ？」と声をかける

---

## 🌙 ネムについて

**ネム** — このアプリのマスコット、三日月の妖精。眠りの見守り役。

- **6表情** — default / happy / worried / sleepy / celebrating / panicking
- **17状態のセリフ** — 課題入力からタイマー超過、深夜アクセスまで、状況に応じたセリフ
- **深夜モード（23時以降）** — 背景が暗くなり、ネムは眠そうな表情に切り替わり、「そろそろ寝よ？」

## 📱 4タブ構造

| タブ | 役割 |
|------|------|
| 🌱 **今日** | 現在のタスクセット、合格ライン、進捗、優先度、締切、タスク編集 |
| ⏱️ **集中** | 選択したタスクのタイマー。円グラフ・超過赤表示・延長ボタン。ネムが主役サイズで見守り |
| 📓 **ログ** | 今日の振り返り（合格ラインとの照合）＋過去の履歴 |
| ⚙️ **設定** | APIキー、通知許可、初回ガイドリセット |

## ✨ v5 機能一覧

| 機能 | 詳細 |
|------|------|
| 🤖 **AI タスク生成** | OpenAI GPT-4o-mini が課題を自動でタスクに分解 |
| 🎁 **サンプルモード** | APIキー無しでもサンプルデータですぐ試せる |
| 🌙 **マスコット「ネム」** | 6表情のSVG+17状態のセリフでユーザーに寄り添う |
| ✨ **合格ライン** | 作業開始前に「今日これができたら合格」を宣言 |
| 📖 **今日の振り返り** | 作業終了時に合格ラインと照合し、達成/未達成をメモとともに記録 |
| ⏱ **円グラフタイマー** | 大画面のカウントダウンタイマー |
| 🔴 **超過タイマー** | 0になっても継続カウントアップ（赤表示）。+5/+10/+15分の延長ボタン |
| 🔔 **音＋ブラウザ通知** | タイマー終了・+15分・+30分でそれぞれ通知 |
| 🌃 **深夜モード** | 23時以降自動で背景が暗くなり、ネムが眠そうに切り替わる |
| 📅 **締め切り設定** | 「あと○日」バッジで残り日数を確認 |
| ⭐ **優先度設定** | 高/中/低で自動ソート |
| 📝 **タスクメモ** | 各タスクに補足メモを追加 |
| 🧭 **初回ガイド** | 「ここを押すと」を矢印・パルス・ネムの吹き出しで案内 |
| 📱 **タブ式UI** | ボトムタブナビゲーション、FAB、ボトムシート型モーダル |
| 💾 **進捗の自動保存** | localStorage で進捗・履歴を永続化 |
| 📚 **履歴管理** | 最大20件の履歴を保存・切り替え・削除 |

## 🎯 推奨フロー

1. 「今日」タブで **「+」FAB** → 新規作成モーダル
2. **課題を入力 → AI分解 or サンプル**
3. **合格ラインを宣言** — 「今日これができたら合格」を1行で
4. タスク行の **タイマーアイコン** → 「集中」タブへ自動遷移
5. **超過したら？** — 音とブラウザ通知が届く。+5/+10/+15分で延長 or ネムに従って休む
6. **「ログ」タブで振り返り** — 合格ラインと照合し、達成/未達を記録
