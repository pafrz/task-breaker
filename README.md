# Task Breaker 🌙

課題を入力すると AI がタスクに分解し、「終わりが見えない作業による徹夜」を**6ステップの体験フロー**で防ぐWebアプリ。見守り役のマスコット「ネム（三日月の妖精）」が各段階で寄り添う。

**🔗 Live Demo:** https://task-breaker-one.vercel.app
（APIキーが無くても「サンプルで試す」で全機能ためせます）

| 項目 | 内容 |
|------|------|
| **アプリ名** | Task Breaker |
| **マスコット** | ネム（三日月の妖精・眠りの見守り役） |
| **構成** | 6ステップの画面遷移型フロー（縦1画面ではなく場面転換） |
| **デザイン** | 「紙と月あかり」— 手書き風のインク + 夜の月色 |
| **目的** | 終わりが見えない作業による徹夜の予防 |
| **対象** | 課題の終わりが見えず長時間作業してしまう学生・社会人 |

## 🎯 課題の背景

> 「レポートを書いていたら満足できず、気づいたら朝5時。AIと壁打ちしていても、気づいたら朝5時。」

作業に没頭すると **時間の感覚がなくなり**、終わりが見えないまま徹夜してしまう。これは開発者自身の原体験で、「完成度に満足できず終われない」という自分のクセから生まれた。

このアプリはそれを4つの仕掛けで扱う：

1. **終わりを先に見える化する** — AIが課題をタスクに分解し、所要時間を見積もる
2. **開始前に"合格ライン"を決める** — 「今日は上から何タスク終えたら合格」を作業前に宣言し、完成後に基準を吊り上げてしまうクセを封じる
3. **超過を音とブラウザ通知で知らせる** — 画面に没頭していても割り込める
4. **ネムが寄り添う** — 状況に応じて表情とセリフを変え、深夜には眠そうに「そろそろ寝よ？」と声をかける

---

## 🪜 6ステップの体験フロー

ひとつの縦長画面に詰め込まず、**6段階の場面転換**として体験させる（ステップレールで現在地が見える／戻れる）。

| # | ステップ | 内容 |
|---|---------|------|
| **1** | 課題入力 | やること・締め切りを入力 → 「AIで分解」または「サンプルで試す」 |
| **2** | AI分解 | 分解されたタスクを確認・編集・追加・削除 |
| **3** | 合格ライン | 「今日は上から何タスク終えれば合格か」を決める（任意で一言ラベルも） |
| **4** | タスク選択 | 今日やるタスクから、いま集中する1つを選ぶ |
| **5** | 集中 | カウントダウンタイマー。超過すると延長 or 切り上げを選べる。この間は盤面が夜になりネムが主役サイズで見守る |
| **6** | 振り返り | 合格ラインを達成できたかを記録。完了タスク数と見積もり時間の合計、一言メモ、明日に残ったタスクを確認 |

> ⚠️ ステップ6の「作業時間」は **完了タスクの見積もり時間の合計** です（ストップウォッチによる実測値ではありません）。

## 🌙 マスコット「ネム」

三日月の妖精。徹夜しそうなユーザーを心配し、寝てくれたら喜ぶ。

- **6表情**（default / happy / worried / sleepy / celebrating / panicking）
- **状況別のセリフ** + タップでの隠しセリフ・ハート演出
- **深夜モード**：23〜5時、または集中中（ステップ5）は盤面が暗転し、ネムが眠そうに切り替わる
- 画像は `public/nem/{表情}.png` を置くと差し替わり、無ければ内蔵SVGにフォールバック

## ✨ 主な機能

| 機能 | 詳細 |
|------|------|
| 🤖 **AI タスク分解** | OpenAI GPT-4o-mini が課題をタスクに分解・時間を見積もり |
| 🎁 **サンプルモード** | APIキー無しでもサンプルデータで全機能をためせる |
| ✨ **合格ライン** | 「上から何タスクで合格か」を開始前に宣言（任意ラベル付き） |
| ⏱ **集中タイマー** | 円形カウントダウン。超過時は +5/+10/+15分の延長 or 切り上げ |
| 🔔 **音＋ブラウザ通知** | タイマー終了・+15分・+30分で通知（Web Audio + Notification API） |
| 📖 **振り返り** | 合格ライン達成の記録・一言メモ・明日への残りタスク表示 |
| 🎉 **達成演出** | 合格ライン到達で紙吹雪＋ファンファーレ |
| 🌃 **深夜モード** | 時間帯・集中中で自動的に夜の盤面へ |
| 📓 **記録** | 過去の課題セットを一覧・再開・削除（最大20件、localStorage） |
| ✏️ **タスク編集** | 名前・時間・メモ・優先度の編集、追加・削除 |
| 🎨 **アニメーション** | ステップ遷移・タスクのバネ物理・進捗のシマー・ネムの呼吸/まばたき |
| ♿ **配慮** | `prefers-reduced-motion` でアニメーション無効化に対応 |

## 🚀 セットアップ

```bash
git clone https://github.com/s24c3118ch-ops/task-breaker.git
cd task-breaker
npm install
npm run dev
```

http://localhost:3000 を開く。
- APIキー無しで試すなら、ステップ1で「サンプルで試す」
- 本物のAI分解を使うなら [OpenAI Platform](https://platform.openai.com/api-keys) で API キー（`sk-...`）を取得し、設定（⚙️）から入力

APIキーはブラウザの localStorage にのみ保存され、分解リクエスト以外では外部送信されません。
