# Task Breaker ⚡

AIが課題をタスクに分解し、「終わりが見えない作業による徹夜」を仕組みで防ぐWebアプリ

**🔗 Live Demo:** https://task-breaker-one.vercel.app  
（APIキーが無くても「🎁 サンプル」ボタンからすぐ試せます）

## 📌 概要

| 項目 | 内容 |
|------|------|
| **アプリ名** | Task Breaker |
| **種別** | Webアプリ（シングルページ） |
| **目的** | 課題・作業のタスク分解と時間管理の両立、徹夜の予防 |
| **対象** | 課題の終わりが見えず長時間作業してしまう学生・社会人 |

---

## 🎯 課題の背景

> 「作業に集中しすぎて、気づいたら深夜になっていた」

作業に没頭すると **時間の感覚がなくなり**、終わりが見えないまま徹夜してしまう。結果として睡眠不足や生活習慣の乱れにつながる。

このアプリは3つのアプローチで解決する：

1. **事前に終わりを見える化する** — AIが課題をタスクに分解し、合計・残り時間を表示
2. **画面を見ていなくても割り込む** — 予定時間を超えたら音とブラウザ通知で知らせる
3. **開始前に合格ラインを宣言する** — 「今日これができたら合格」を作業前に決めておき、終了後に照合する。完成後に基準を吊り上げる癖を仕組みで殴る

## ✨ v4 の機能一覧

| 機能 | 詳細 |
|------|------|
| 🤖 **AI タスク生成** | OpenAI GPT-4o-mini が課題を自動でタスクに分解・時間見積もり |
| 🎁 **デモモード** | APIキーが無くてもサンプルデータで動作を試せる |
| ✨ **合格ライン** | 作業開始前に「今日これができたら合格」を宣言 |
| 📖 **今日の振り返り** | 作業終了時に合格ラインと照合し、達成/未達成をメモとともに記録 |
| ⏱ **カウントダウンタイマー** | タスクごとに作業タイマー。円グラフで残り時間を可視化 |
| 🔴 **超過タイマー** | 0になっても継続カウントアップ（赤表示）。+5/+10/+15分の延長ボタン |
| 🔔 **音＋ブラウザ通知** | タイマー終了時に音とデスクトップ通知（画面外でも気づける） |
| 📅 **締め切り設定** | 「あと○日」バッジで残り日数を確認 |
| ⭐ **優先度設定** | 高/中/低で自動ソート |
| 📝 **タスクメモ** | 各タスクに補足メモを追加 |
| ✏️ **タスク編集** | タスク名・時間をインライン編集・追加・削除 |
| 💾 **進捗の自動保存** | localStorage で進捗・履歴を永続化 |
| 📚 **履歴管理** | 最大20件の履歴を保存・切り替え |
| 📱 **スマホ対応** | レスポンシブデザイン。タップ操作最適化 |

## 🚀 セットアップ

## 🎯 使い方（推奨フロー）

1. **課題を入力** → 「AIで分解する」または「🎁 サンプル」
2. **合格ラインを宣言** — 「今日これができたら合格」を1行で書く（開始前に）
3. **タイマーで作業** — タスクのタイマーを起動して集中
4. **超過したら？** — 音とブラウザ通知が届く → 延長するか、いったんやめるか判断
5. **1日の終わりに振り返り** — 開始前の合格ラインと照合し、達成/未達成を記録
